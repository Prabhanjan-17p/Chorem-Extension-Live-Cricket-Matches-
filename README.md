# 🏏 Chorem Extension - Live Cricket Matches

A **Chrome Extension** that provides **real-time live cricket scores** and match updates using **HTML, CSS, JavaScript, and APIs**.  
Stay updated with the latest scores right from your browser without navigating through multiple websites.

## ✨ Features
- 🟢 **Live Cricket Score Updates** inside the extension popup  
- 📊 **Match Info** – teams, overs, runs, wickets  
- 🎨 **Simple & Clean UI** built with HTML, CSS, and JS  
- ⚡ **Lightweight Chrome Extension** that runs instantly
